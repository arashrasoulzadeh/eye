# اجزای پنل

پنل مدیریت با Next.js و React ساخته شده است.

| جزء | کاربرد |
|---|---|
| `Card`, `StatCard` | کارت و شاخص |
| `DataTable` | جدول داده |
| `LineTrend`, `BarBreakdown` | نمودار |
| `Badge` | نشان وضعیت |
| `Button`, `Input`, `Combobox` | کنترل ورودی |
| `JsonView` | مشاهده JSON |
| `ConfirmDialog` | تأیید عملیات |
| `Toast`, `useToast` | پیام وضعیت |
| `EntityLink` | پیوند موجودیت |
| `LiveSession`, `LiveCounter` | داده زنده |
| `Sidebar` | ناوبری |

```tsx
<StatCard label="Events" value={1234} />
```

برای قرارداد دقیق پراپ‌ها و مثال‌های بیشتر به نسخه انگلیسی مراجعه کنید.
