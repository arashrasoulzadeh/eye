# فهرست مسیرهای برنامه

مسیرهای زیر از فایل‌های صفحه استخراج شده‌اند. وجود مسیر به معنای دسترسی همه نقش‌ها نیست.

| مسیر | کاربرد |
|---|---|
| `/dashboard` | نمای کلی |
| `/analytics` | گزارش‌های آماده و پیشرفته |
| `/analytics/funnel` | تحلیل قیف |
| `/analytics/retention` | تحلیل بازگشت کاربران |
| `/dimensions` | تحلیل ابعاد |
| `/query` | پرس‌وجوی SQL فقط خواندنی |
| `/events` | مرور رویدادها |
| `/events/[id]` | جزئیات رویداد |
| `/sessions` | مرور نشست‌ها |
| `/sessions/[id]` | جزئیات نشست |
| `/users` | مرور کاربران |
| `/users/[id]` | پروفایل کاربر |
| `/stream` | فعالیت زنده |
| `/graphs` | نمودارها |
| `/questions` | پرسش‌ها |
| `/tenants` | مدیریت مستأجرها |
| `/tenants/[id]` | جزئیات مستأجر |
| `/admin-users` | کاربران مدیر |
| `/admin-teams` | تیم‌های مدیریتی |
| `/schemas` | طرح رویداد |
| `/cohorts` | گروه کاربران |
| `/aggregations` | تجمیع داده |
| `/experiments` | آزمایش‌ها |
| `/feature-flags` | پرچم قابلیت |
| `/alerts` | هشدارها |
| `/anomalies` | ناهنجاری‌ها |
| `/intelligence` | نمای کلی هوشمندی |
| `/intelligence/labels` | برچسب‌های هوشمندی |
| `/intelligence/models` | مدیریت مدل |
| `/intelligence/training` | آموزش مدل |
| `/health` | سلامت سامانه |
| `/operations` | عملیات |
| `/slo` | اهداف سطح خدمت |
| `/audit-log` | گزارش حسابرسی |
| `/dead-letters` | ارسال‌های ناموفق وب‌هوک |
| `/compression` | فشرده‌سازی |
| `/replay` | بازپخش رویداد |
| `/settings` | تنظیمات |
| `/test-event` | آزمون رویداد |
| `/cdn-test` | آزمون CDN |
| `/login` | ورود |
| `/` | ورودی برنامه |
