# تحلیل و کاوش

## ابعاد

مستأجر و بازه زمانی سراسری را انتخاب کنید. نوع رویدادها را اضافه کنید و بعد گروه‌بندی، بعد تفکیک و عملیات تجمیع را تعیین کنید. با فعال کردن بازکردن آرایه‌ها، عناصر یکتای هر آرایه جداگانه شمارش می‌شوند. در بخش پیشرفته می‌توانید بازه‌های زمانی، فیلتر ابعاد و مقایسه را تنظیم کنید. پیش از تفسیر نتیجه، تعداد رویدادهای بررسی‌شده، گروه‌ها و مقادیر معتبر را بررسی کنید. نتیجه را در جدول جستجو کنید یا نمودار را انتخاب کنید.

## محیط SQL

پرس‌وجوهای فقط خواندنی روی رویدادها اجرا می‌شوند. از پیشنهادهای طرح داده، تاریخچه و گزینه بازه زمانی سراسری استفاده کنید. نتیجه قابل مرتب‌سازی، نمایش نموداری و خروجی CSV یا JSON است.

```sql
SELECT type, COUNT(*) AS total FROM events GROUP BY type ORDER BY total DESC;
```

```sql
SELECT type, timestamp, user_id FROM events ORDER BY timestamp DESC LIMIT 20;
```

فقط عبارت‌های پیاده‌سازی‌شده پشتیبانی می‌شوند؛ پیشنهاد ویرایشگر تضمین پشتیبانی سرور نیست.
