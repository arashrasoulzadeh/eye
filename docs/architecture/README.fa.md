# معماری سامانه

SDK وب، SDK گو و گردآورنده gRPC داده‌ها را به سرور Go می‌فرستند. سرویس دریافت، اعتبارسنجی و ثبت رویداد را انجام می‌دهد؛ سرویس پرس‌وجو داده‌ها را برای پنل و API آماده می‌کند.

## ذخیره‌سازی و پردازش

SQLite برای توسعه و PostgreSQL/TimescaleDB برای استقرار مناسب پیکربندی می‌شوند. مدل‌های اصلی شامل نشست، رویداد و شمارنده تجمیعی هستند. جریان SSE برای به‌روزرسانی زنده و gRPC برای جریان داده استفاده می‌شود.

## سرویس‌ها

- دریافت همزمان و غیرهمزمان، اعتبارسنجی طرح و حذف تکرار
- مدیریت نشست و شمارنده زنده
- پرس‌وجو با فیلتر مستأجر، زمان و ابعاد
- مدیریت مستأجر، هشدار، آزمایش و گروه کاربران
- وظایف پس‌زمینه برای نگهداری، تجمیع، پشتیبان‌گیری و تشخیص ناهنجاری

## امنیت و عملیات

کلیدها را جدا نگه دارید، دسترسی مدیریتی را محدود کنید و سیاست نگهداری داده را تنظیم کنید. پیش از مهاجرت پایگاه داده پشتیبان تهیه کنید. برای جزئیات ساختارهای Go و قرارداد سرویس‌ها نسخه انگلیسی را ببینید.
