# شروع کار

برای اجرای محلی به Go 1.26 و Node.js سازگار با وابستگی‌های پنل نیاز دارید.

```bash
git clone https://github.com/arashrasoulzadeh/eye.git
cd eye
cd admin && npm ci && cd ..
make server
```

در ترمینال دیگری دستور `make admin` را اجرا کنید. پنل در http://localhost:3000 و API در پورت 8080 در دسترس است. پورت gRPC برابر 50052 است.

## پیکربندی

فایل محیطی پروژه را مطابق تنظیمات سرور آماده کنید. کلید مدیر را فقط در محیط امن نگه دارید. برای توسعه از SQLite و برای استقرار مبتنی بر PostgreSQL از تنظیمات مناسب مخزن استفاده کنید.

## اولین رویداد

۱. وارد پنل شوید و یک مستأجر بسازید.

۲. کلید همان مستأجر را در SDK تنظیم کنید.

۳. یک نشست ایجاد کنید و رویدادی مانند `page_view` بفرستید.

۴. مستأجر و بازه زمانی مناسب را در پنل انتخاب کنید.
