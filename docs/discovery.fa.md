# کشف امکانات Eye

## تحلیل محصول

با گزارش‌های آماده شروع کنید، سپس رویداد و بازه زمانی را تغییر دهید. برای مقایسه ویژگی‌های رویداد از تحلیل ابعاد و برای پرس‌وجوی سفارشی از محیط SQL استفاده کنید. پشتیبانی SQL محدود به قابلیت‌های پیاده‌سازی‌شده است.

## مدیریت داده

رویدادها، نشست‌ها، کاربران، طرح‌ها، مستأجرها، گروه‌ها، هشدارها و آزمایش‌ها را از بخش‌های مربوط بررسی کنید.
