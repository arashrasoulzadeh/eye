# مرجع API

آدرس محلی REST برابر `http://localhost:8080` و gRPC برابر `localhost:50052` است.

## احراز هویت

برای دریافت رویداد از هدر `x-api-key` و برای عملیات مدیریتی از `x-admin-key` استفاده کنید. جریان‌های زنده مدیریتی از احراز هویت مبتنی بر کوکی استفاده می‌کنند.

| مسیر | کاربرد |
|---|---|
| `POST /sessions` | ایجاد نشست |
| `POST /ingest` | دریافت دسته‌ای رویداد |
| `POST /ingest/stream` | دریافت غیرهمزمان |
| `POST /query` | جستجوی رویداد |
| `GET /events` | مرور رویدادها |
| `GET /analytics/buckets` | شمارش تاریخی |
| `GET /live-counters` | شمارنده زنده |
| `GET /live-session` | وضعیت نشست |
| `GET /live-events` | جریان رویداد |
| `/tenants` | مدیریت مستأجر |
| `/schemas` | طرح داده |
| `/cohorts` | گروه کاربران |
| `/alerts` | هشدارها |
| `/settings` | تنظیمات |

## نمونه دریافت رویداد

```json
{"events":[{"session_id":"session-id","event_id":"evt-001","event_name":"click","client_ts":1705315800000,"payload":{"button":"signup"},"dims":{"plan":"pro"}}]}
```

## خطاها

کد 400 برای درخواست نامعتبر، 401 برای احراز هویت ناموفق، 403 برای دسترسی غیرمجاز، 404 برای منبع ناموجود، 429 برای محدودیت نرخ و 500 برای خطای داخلی است.

برای قرارداد کامل درخواست‌ها و پیام‌های gRPC به نسخه انگلیسی مراجعه کنید.
