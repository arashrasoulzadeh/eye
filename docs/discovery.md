# Discover Eye

Use this map to find the right part of the platform.

| Goal | Workspace |
|---|---|
| Understand activity | Dashboard and guided Analytics |
| Compare event properties | Dimensions |
| Investigate raw records | Events and SQL explorer |
| Understand journeys | Sessions, Users and Funnels |
| Monitor current traffic | Live Stream |
| Manage isolation and access | Tenants and Settings |
| Validate event contracts | Schemas |
| Segment audiences | Cohorts |
| Monitor thresholds | Alerts |
| Compare variants | Experiments |
| Investigate model quality | Intelligence and observability |

## First analysis

Select a tenant and global time range. Start with Overview, then choose an event and a dimension. Inspect raw events to validate unexpected results. Counts depend on the selected scope and available data.
